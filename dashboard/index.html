Operational threat posture: Project Aegis provides autonomous zero-trust boundary defense on all file writes. Conventional endpoint security runs in user space, allowing ransomware to encrypt tens or hundreds of documents before heuristics detect anomalous behavior. Aegis operates synchronously inside the Linux kernel, preventing unauthorized modifications from reaching the disk surface.

Attached kernel probes

Compiled via clang with -target bpf and verified with BTF CO-RE.

proc_state_map : LRU_HASH (8192 entries) canary_set : HASH (1024 entries) nlog2n_tab : ARRAY (4097 entries, Q16) events : RINGBUF (2 MB memory ring)

Zero user-kernel context transitions during write-path inspection.

1. Fixed-point Miller-Madow entropy

Because the Linux kernel forbids floating-point registers, Aegis computes Shannon entropy using $Q16.16$ integer math and integer lookup tables with asymptotic bias correction:

H_MM = (T[N] - Sum(c_i*log2(c_i)))/N + (K_obs - 1)*47274/N

2. Exponential risk decay

To avoid false positives from legitimate compression or compiling, evidence decays with a half-life of 4 seconds using fast integer bit-shifts in $Q8.8$:

R(t) = R_0 >> (elapsed_ms / 4000)
